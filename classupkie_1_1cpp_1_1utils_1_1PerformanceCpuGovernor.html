Detailed Description

Set all CPU cores to the "performance" frequency governor while in scope.

Latency-sensitive processes such as the pi3hat spine want all cores running at maximum frequency rather than dynamically scaling. This class switches CPU frequency governors to "performance" upon configure, and restores the governors found at startup when it is destroyed.

Writing CPU frequency governors requires root privileges.
